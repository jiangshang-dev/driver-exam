# 驾考通 - 驾考学习APP原型

这是一个专业的驾考学习平台原型，采用HTML+CSS+JavaScript技术栈开发，适配移动端APP体验。

## 功能特色

### 🎥 交规视频学习
- VIP会员专享视频课程
- 专业教练在线指导
- 视频点赞、收藏功能
- 评论互动交流

### 📚 驾考刷题系统
- 按题型分类练习
- 科目一、科目四全覆盖
- 详细答案解析
- 错题本收集

### 📝 模拟考试
- 真实考试环境模拟
- 智能评分系统
- 错题分析报告
- 历史成绩查看

### 👤 个人中心
- 多种登录方式支持
- 学习进度跟踪
- 积分系统
- VIP会员管理

### 🎨 界面设计
- 现代化UI设计
- 移动端优化
- 响应式布局
- 流畅动画效果

## 技术特点

- **纯前端实现**：HTML5 + CSS3 + ES6
- **移动端优化**：响应式设计，适配各种屏幕
- **组件化架构**：模块化JavaScript代码
- **本地存储**：LocalStorage数据持久化
- **动画效果**：CSS3动画提升用户体验

## 登录支持

### 🔐 多种登录方式
- 华为账号一键登录
- 微信第三方登录
- 支付宝第三方登录
- 手机号验证码登录

## 页面结构

```
├── index.html          # 首页
├── questions.html      # 刷题页面
├── exam.html          # 模拟考试
├── profile.html       # 个人中心
├── videos.html        # 交规视频
├── css/
│   ├── common.css     # 通用样式
│   ├── index.css      # 首页样式
│   ├── questions.css  # 刷题样式
│   ├── exam.css       # 考试样式
│   ├── profile.css    # 个人中心样式
│   └── videos.css     # 视频页面样式
└── js/
    ├── common.js      # 通用功能
    ├── index.js       # 首页逻辑
    ├── questions.js   # 刷题逻辑
    ├── exam.js        # 考试逻辑
    ├── profile.js     # 个人中心逻辑
    └── videos.js      # 视频页面逻辑
```

## 使用说明

1. **直接打开**: 使用浏览器打开 `index.html` 即可运行
2. **本地服务器**: 推荐使用本地服务器运行以获得更好体验
3. **移动端测试**: 使用浏览器开发者工具的移动端模拟器测试
